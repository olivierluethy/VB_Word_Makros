# VB Word Makros
Codebausteine welche in Word integriert und ausgeführt werden können. Bei der Entwicklung handelt es ist um die Sprache Visual Basic.

## Makro Editor in Word öffnen
Alt + F11 -> Um in Word Dokument zum Makro Editor zu gelangen und das Makro im Dokument hineinzukopieren. Der Code kann in Editor ausgeführt werden.

## Dateinamenendung
Die Datei Endung muss aber .docm sein um Makros zu erlauben.
